# Contributing to WooCommerce Boilerplate

We welcome contributions! Here's how to get involved:

## Getting Started

1. Fork the repository
2. Clone your fork locally
3. Create a new branch for your feature or fix
4. Make your changes
5. Commit with clear messages following WordPress Coding Standards
6. Push to your fork
7. Submit a pull request

## Code Standards

Please follow the [WordPress Coding Standards](https://developer.wordpress.org/coding-standards/):

- Use proper indentation (4 spaces for PHP, 2 spaces for JS)
- Use camelCase for variable names
- Use descriptive function names
- Add comments for complex logic
- Follow [WordPress Security Best Practices](https://developer.wordpress.org/plugins/security/)

## Pull Request Process

1. Update documentation as needed
2. Add/update unit tests if applicable
3. Ensure all code passes linting
4. Provide a clear description of your changes
5. Link to any related issues
